## How to act on this report

1. **§1 (no Initiative):** for each, decide whether to file a new Jira Initiative or fix the `crate-<name>` label on an existing one. Cargo renames are already resolved, so what's left here is real-published-crate-name vs label-name divergence.
2. **§2 (skip-list violations):** push each crate's `ordered_priority` away from 0 in Jira. Their stated 0 came from the Jira Blocks graph, which can't see test-only or sandbox dependencies.
3. **§3 + §4 (under-prioritized):** real codex usage is the ground-truth signal. Bump the Jira rank to reflect actual blast radius.
4. **§5 (stated-but-unused top-30):** confirm each 0-edge crate's high rank is justified by a non-codex consumer still on the roadmap; if not, demote.

Re-run: `python scaffold/audit_codex_priority.py`. Output is byte-stable across runs with the same source state.
